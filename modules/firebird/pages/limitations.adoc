= Ограничения Firebird

В этом разделе собраны известные ограничения и особенности работы Firebird с Jmix, обнаруженные в ходе практического использования.

[[unofficial-support]]
== Поддержка через аддон

Firebird поддерживается в Jmix через аддон https://www.jmix.ru/marketplace/firebird-db/[Firebird в Jmix Marketplace^]. Аддон обеспечивает использование Firebird в качестве основной базы данных приложения.

Аддон `jmix-firebird-addon` сопровождается отдельно от основной платформы Jmix.

[[changelog-generation]]
== Автогенерация Liquibase changelog

Для СУБД, которые Jmix поддерживает штатно, Studio перед запуском сравнивает модель данных со схемой базы и может автоматически сформировать Liquibase changelog для недостающих объектов. Для Firebird этот механизм недоступен: Studio не создаёт changeset-ы по изменениям модели и не предлагает готовое обновление схемы.

Поэтому при добавлении сущности, атрибута, связи, индекса или другого объекта разработчик должен самостоятельно определить необходимые изменения базы данных, описать их в XML-changelog, выбрать подходящие типы и change types с учётом Firebird. Это основной практический блокер, поскольку каждое изменение модели требует ручной подготовки и проверки соответствующего изменения схемы.

Ограничение относится только к автоматической генерации. Созданные вручную changelog-и нормально выполняются Liquibase при запуске приложения, поэтому подготовленную миграцию можно применять тем же способом, что и для других СУБД.

[TIP]
====
Пример создания Liquibase changelog можно посмотреть в xref:tutorial:data-in-ui.adoc#joining-date-attr[разделе самоучителя о добавлении атрибута joiningDate]. В нём приведены инструкции по созданию changelog с одним changeset и описаны внесённые изменения.

Более подробно процесс создания Liquibase changelog описан в отдельном разделе xref:liquibase-changelog.adoc[Создание Liquibase changelog].
====

[[third-party-support]]
== Поддержка Firebird в сторонних библиотеках

В Jmix для работы с базой данных используются Liquibase и EclipseLink. Liquibase отвечает за управление схемой базы данных и выполнение changelog, а EclipseLink обеспечивает работу приложения с базой данных.

Обе библиотеки уже содержат поддержку Firebird. Однако часть этой поддержки была реализована для старых версий Firebird, поэтому некоторые ограничения и проверки могут быть неактуальны для современных версий СУБД.

[[sequence-start-value]]
=== Пример: createSequence и startValue

При создании sequence Liquibase запрещал атрибут `startValue` для Firebird независимо от версии базы данных. Такой changeset:

[source,xml]
----
<createSequence sequenceName="CRM_PAYMENT_NUMBER" startValue="1000"/>
----

завершался ошибкой:

[source]
----
startValue is not allowed on firebird
----

Для Firebird 4.0 и новее это ограничение уже неактуально. Оно относится к реализации Firebird в Liquibase, а не к Jmix, поэтому корректное исправление должно вноситься непосредственно в Liquibase.

В `jmix-crm-firebird` для запуска проекта применён временный workaround: обычный changeset исключает Firebird, а отдельный Firebird-changeset создаёт sequence без `startValue` и затем устанавливает начальное значение SQL-командой:

[source,xml]
----
<changeSet id="1" author="crm" dbms="!firebird">
    <createSequence sequenceName="CRM_PAYMENT_NUMBER" startValue="1000"/>
</changeSet>

<changeSet id="2" author="crm" dbms="firebird">
    <createSequence sequenceName="CRM_PAYMENT_NUMBER"/>
    <sql>ALTER SEQUENCE CRM_PAYMENT_NUMBER RESTART WITH 1000</sql>
</changeSet>
----

Полный пример можно посмотреть в https://github.com/makssent/jmix-crm-firebird/commit/724d0a46f18aa9188a7e847e03fedf2fb74456f9[коммите проекта jmix-crm-firebird^].

Исправление для корректной работы startValue отправлено непосредственно в Liquibase: https://github.com/liquibase/liquibase/pull/7922[PR #7922^].

== Заключение

Здесь перечислены ограничения, известные на данный момент. При прохождении самоучителя, работе с реальным приложением `jmix-crm` и запуске его тестов дополнительных ограничений не обнаружено. При дальнейшем использовании Firebird с Jmix могут проявиться другие особенности.
